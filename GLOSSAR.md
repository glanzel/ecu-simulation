# Kurzglossar Benennung (Domäne)


| Code / Variable / Funktionsname | Bedeutung                                                                                                                                                                                  | Bezeichnung UI               | Auch / anders benannt                                                                                                     |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| `budget_J`                      | Langfristiges planetares Ziel je Grenze (Jahres-Obergrenze, physische Verschmutzungseinheiten/a).                                                                                          | BudgetJ                     | z. B. `budget_J["co2"]` (`vej_jahr_soll_lang`)                                                                            |
| `vej_soll` | Im Modell nicht als eigener Wert geführt; fachlich deckungsgleich mit Jahres-``budget_J`` (kein separates Datenfeld). | — | früher „VEJ-Soll (Jahr)“; **nicht** ``ve_soll`` (reserviert). |
| `budget_T` | Monatsanteil des BudgetJs: ``budget_J / 12`` (Monats-Obergrenze je Grenze). | BudgetT | z. B. `budget_T["co2"]` |
| `nutzung_T`                       | Beobachteter bzw. modellierter Verbrauch pro Monat (gleiche Einheit wie `budget_T`).                                                                                                       | NutzungT                      | z. B. `nutzung_T["co2"]`                                                                                                    |
| `nutzung_anteil_budget`          | Anteil am BudgetJ (Referenznachfrage / Startanker), dimensionslos 0…1.                                                                                                                  | Start-Nachfrage (Anteil) | —                                                                                                                         |
| `demand_at_reference_price`     | Nachfragemenge bei Referenz-ECU-Preis (pro Monat je Grenze); Eingang der isoelastischen Kurve (`consumption_quantity`), inkl. Wachstum/Rauschen aus der Simulation.                    | demand                       | z. B. `demand_at_reference_price["co2"]`; in `ConsumptionRecord` optional                                                 |
| `consumption_quantity`          | Aus `demand_at_reference_price` und Preisverhältnis berechnete Menge zum aktuellen `ecu_preis` (Vorstufe); danach ggf. `apply_consumption_budget` → gespeicherter Ist-Konsum `nutzung_T`. | consum (Kurve)               | Funktion in `simulation/demand.py`; Rohwerte `_raw_nutzung_T_at_prices`                                                     |
| `ecumenge_ziel`               | Konfiguriertes langfristiges Jahresziel (ECU/Jahr); Referenz für Slack ggü. `ecu_summe_p_budget_J` und für Preisnormierung Σ ecu_preis·BudgetJ-Ziel.                                                   | ECU-Ziel (Jahr)              | `SimulationConfig.ecumenge_ziel`; Timeline-Feld gleicher Name; `ecumenge_ziel_konfig` = unveränderte Konfigkopie       |
| `ecu_summe_p_budget_J`                    | ECU-Kosten volles Budget (Jahr): Σ p_i·budget_J_i zu den gültigen ECU-Preisen. Im ECU-Diagramm als **Monatsanteil** `ecu_summe_p_budget_T` (÷12).               | ECU-Kosten Budgets (Jahr)     | `PeriodResult.ecu_summe_p_budget_J`; weicher Pfad: schrittweise Annäherung an `ecumenge_ziel_sim`, nicht jeden Monat exakt `ecumenge_ziel`. |
| `ecumenge_ziel_sim`           | Simuliertes langfristiges Jahresziel (weicher Pfad: wirksamer Wert nach Ratchet; sinkt höchstens um p %/Periode bis `ecumenge_ziel_konfig`).                                             | ECU-Ziel sim. (Jahr)         | `ratchet_ecumenge_ziel_sim`; monatlich ÷12 als Referenz (`warmup_diag_ecumenge_ziel_sim_monthly`, Diagramm `ecumenge_ziel_sim_T`) |
| `ecumenge_J`                    | Simulierte wirksame Jahresmenge (Start bzw. Ausgang für die Budgetlogik; bei hoher Start-Auslastung ≥ `ecumenge_ziel`).                                                                  | ECU-Menge J (sim.)           | `ecumenge_J_from_start`; erste Periode: Grundlage für `ecumenge_T`/`12`                                                    |
| `ecumenge_T`                    | Im Zeitschritt simuliert ausgegebene ECU-Menge (Budgetobergrenze für Σ p·c in dieser Periode).                                                                                               | ECU-Menge T (sim.)           | `ecumenge_T_override` (weicher Pfad); frühere Sprechweise „ECU-Decke“ / Monats-Cap                                         |
| `ecu_ist_T`                     | Tatsächlich verbuchte ECU im Zeitschritt (Σ p·nutzung_T zum gespeicherten Konsum).                                                                                                             | ECU-Ist (Monat)              | gegenüber `ecumenge_T`; Grenztabelle: Spalte **Ecu NutzungT** = p·nutzung_T je Grenze                                       |
| `quote_T`                       | Ziel-Quote: ``f`` steigt um Deltagesamt pro Schritt solange Gesamtauslastung > 1 (danach ``f`` eingefroren), ``Quote_t_k = Nutzung_t0_k·(1−f)+Budget_t_k·f``; bei ``f≥1``: ``Budget_t_k``. Ecumenge-Ratchet nur bei G>1. | Quote_t                      | `logic.quota.QuotaCalculator`; `timeline.last_quota`; `timeline.quote_absenkung_f`                                         |
| `delta_T`                       | Grenzanteil von Deltagesamt: ``Deltagesamt · AuslastungT / GesamtauslastungT``.                                                                                                                | DeltaT                       | in `BoundaryQuotaStep.delta_T`                                                                                              |
| `elastikfaktor`                 | Kybernetischer Preisfaktor je Grenze (Text, ab Preisschritt 5); nicht identisch mit `geschaetzte_preiselastizitaet` (OLS, soft_path).                                                          | Elastikfaktor                | `ElasticityFactorTracker` in `logic.elasticity_factor`                                                                      |
| `geschaetzte_preiselastizitaet` | OLS-η aus ln(NutzungT) ~ ln(ECU-Preis) (nur `price_algorithm=soft_path`).                                                                                                                     | —                            | `_geschaetzte_preiselastizitaet_*` in `logic/prices.py`                                                                     |
| `deltagesamt_pct`               | Politisch festgelegter Prozentfaktor pro Zeitschritt (Text: Deltagesamt).                                                                                                                      | Deltagesamt %                | `PriceConfig.deltagesamt_pct`                                                                                               |


**UI / Tabellen:** Lesbare Kurzbezeichnungen ohne Unterstriche (siehe Spalte *Bezeichnung UI*); in der CLI v. a. in Tabellenlegenden (`cli_simulation.py`). Wo die Oberfläche die Code-Symbole zeigt, entsprechen sie den Namen in der ersten Spalte (`ecumenge_*`, `ecu_ist_*`, Suffix `_J` = Jahr, `_T` = Zeitschritt).
